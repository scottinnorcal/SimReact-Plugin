Internal plugin to speed up building and maintaining the SimReact marketing site.

== Description ==

This is an internal WordPress plugin designed to accelerate the creation and maintenance of the SimReact marketing site using the Cadence theme and Gutenberg block editor.

== Installation ==

1. Upload the `simreact-site-builder` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access the SimReact Builder from the admin menu.
